# Track My Finance

A modern Android application built with Jetpack Compose to help users track and manage their personal finances.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Architecture**: MVVM
- **Dependency Injection**: Dagger Hilt
- **Concurrency**: Kotlin Coroutines
- **Android Jetpack Components**:
  - ViewModel
  - Compose Navigation
  - Material Design 3

## Project Setup

### Requirements

- Android Studio Hedgehog | 2025.1.1 or newer
- JDK 17 or newer
- Android SDK API 36 (Android 16.0)
- Kotlin 2.0.21 or newer

### Building the Project

1. Clone the repository:
```bash
git clone https://github.com/your-username/TrackMyFinance.git
```

2. Open the project in Android Studio

3. Sync the project with Gradle files

4. Run the app on an emulator or physical device

## Development Environment Setup

Ensure you have the following configured:
- Latest Android Studio version
- Android SDK Platform 36
- Android SDK Build-Tools
- Android Emulator (optional)
