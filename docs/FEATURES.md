# Feature Planning Document

## Overview
Track My Finance is divided into three major features that help users manage their finances holistically:

1. **Earn-It**: Income tracking and management
2. **Invest-It**: Investment portfolio and tracking
3. **Spend-It**: Expense tracking and budgeting

## Feature Details

### 1. Earn-It 📈
Track and manage all sources of income.

#### Key Features
- Multiple income source tracking
- Regular vs One-time income categorization
- Income analytics and trends
- Tax category assignments
- Payment reminders
- Income goals setting

#### Screen Components
1. **Income Dashboard**
   - Monthly income overview card
   - Income vs Goal progress bar
   - Recent transactions list
   - Quick add income FAB

2. **Add/Edit Income Screen**
   - Income amount input
   - Source selection/creation
   - Date picker
   - Category selection
   - Recurring income toggle
   - Payment method
   - Notes/attachments

3. **Income Analytics**
   - Monthly/yearly income charts
   - Source-wise distribution
   - Income trends
   - Category-wise breakup
   - Tax liability estimates

### 2. Invest-It 💰
Manage and track investments across different instruments.

#### Key Features
- Portfolio management
- Investment tracking
- Returns calculator
- Investment suggestions
- Goal-based investing
- Risk assessment

#### Screen Components
1. **Investment Dashboard**
   - Portfolio value card
   - Asset allocation chart
   - Performance metrics
   - Quick invest FAB
   - Active investments list

2. **Add/Edit Investment Screen**
   - Investment type selection
   - Amount input
   - Investment date
   - Expected returns
   - Risk level indicator
   - Investment goals linking
   - Documents upload

3. **Investment Analytics**
   - Returns overview
   - Asset allocation view
   - Goal progress tracking
   - Market value vs Invested amount
   - Historical performance charts

### 3. Spend-It 💸
Track expenses and manage budgets.

#### Key Features
- Expense tracking
- Budget management
- Category-wise spending
- Bill reminders
- Spending insights
- Split expenses

#### Screen Components
1. **Expense Dashboard**
   - Monthly budget overview
   - Category-wise spending cards
   - Recent transactions
   - Quick add expense FAB
   - Bill payment reminders

2. **Add/Edit Expense Screen**
   - Amount input
   - Category selection
   - Date picker
   - Payment method
   - Split expense option
   - Receipt upload
   - Location tagging
   - Notes

3. **Budget Analytics**
   - Monthly spending overview
   - Category-wise analysis
   - Trend analysis
   - Budget vs Actual comparison
   - Saving suggestions

## Common UI Elements

### Navigation
- Bottom Navigation Bar with:
  - Earn-It
  - Invest-It
  - Spend-It
  - Overview/Dashboard

### Theme
- Material Design 3 with dynamic theming
- Light/Dark mode support
- Custom color schemes for each feature section:
  - Earn-It: Green palette
  - Invest-It: Blue palette
  - Spend-It: Purple palette

### Components
1. **Cards**
   - Elevated cards for important metrics
   - Outlined cards for lists
   - Custom cards for data visualization

2. **Lists**
   - Transaction lists with swipe actions
   - Category lists with icons
   - Account lists with balances

3. **Charts**
   - Line charts for trends
   - Pie charts for distributions
   - Bar charts for comparisons
   - Area charts for growth

4. **Action Buttons**
   - FABs for primary actions
   - Extended FABs for guided actions
   - Speed dial FABs for multiple actions

## Animation and Interaction
- Smooth transitions between screens
- Material motion patterns
- Interactive charts with animations
- Pull to refresh
- Swipe to delete/edit
- Gesture navigation
